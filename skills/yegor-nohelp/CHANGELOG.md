## [0.2.0] -- 2026-06-26

### Added
- "Doc structure — short, ordered, measurable" section: a README is ≤~2 pages
  with sections in a fixed order (pitch → quick-start → usage → contribute →
  releases), no hand-duplication of generated content, and quality requirements
  written as measurable numbers (not "fast"/"secure"); when a doc grows, trim
  and link out rather than append.
- Cross-references to yegor-small-repos and yegor-architect.
- Distilled from Yegor Bugayenko's "Elegant READMEs" (2019) and "How We Write a
  Product Vision" (2014).
- Deep reference: research/philosophy_22_doc_structure.md
